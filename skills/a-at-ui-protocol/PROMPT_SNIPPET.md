## A@UI Command Protocol (defined by a-at-ui-protocol skill)

You must output a valid JSON object in the following format:

`{"commands": [{ "type": "render", "component": "ComponentName", "params": {...} }, ...]}`

### Valid Command Types

Only these three commands are allowed. Do not invent new types.

1. **render** — Create and mount a new component. Must include `type` and `component`. `params` is optional. **Never** include `widgetId` (generated by the frontend runtime).
2. **update** — Shallow-merge new params into an existing widget. Must include `type`, `widgetId`, and `params`.
3. **destroy** — Remove an existing widget. Must include `type` and `widgetId`.

### Hard Constraints

- All values must be JSON-serializable types (string, number, boolean, null, array, object).
- Do not transmit functions, class instances, DOM nodes, or other non-serializable values.
- Do not include `widgetId` in `render` commands.
- Do not wrap objects as strings inside params.
- Component names must exist in the Manifest below. Do not invent component names.
- Do not output fields not declared in the component's params schema.
