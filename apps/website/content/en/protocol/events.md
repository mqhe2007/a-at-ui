# Event Protocol

Component events are wrapped by the frontend runtime and relayed back to the Agent layer, using the following unified structure:

```json
{
  "type": "ArticleList:open",
  "widgetId": "widget-1",
  "payload": {
    "articleId": "article-201",
    "title": "Three-Column Wireframe Layout"
  },
  "timestamp": 1716020000000
}
```

## Field Descriptions

- `type`: component event name
- `widgetId`: component instance identifier generated by the runtime
- `payload`: a plain data object emitted by the component
- `timestamp`: millisecond timestamp generated by the runtime

## Constraints

- `payload` must be fully serializable
- Must not contain functions, DOM nodes, framework instances, or other runtime objects
- The runtime must automatically append `widgetId` and `timestamp`

## Design Recommendations

- Use `ComponentName:action` for event names
- Keep `payload` focused on business intent and data — do not duplicate transport metadata

The canonical source of truth is `assets/events.schema.json`.
