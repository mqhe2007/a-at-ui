# braid

[中文](https://github.com/mqhe2007/braid/blob/main/packages/braid/README.zh-CN.md)

Frontend runtime and protocol assets for agent-driven UI streams.

## Install

```bash
npm install braid
```

## Exports

- `braid`: package entry for protocol types and shared utilities
- `braid/runtime/vue`: Vue 3 frontend runtime adapter

## Usage

Use the official frontend runtime adapter for your target frontend stack. See the full documentation at https://braid.mengqinghe.com.
