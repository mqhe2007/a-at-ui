# a-at-ui

[中文](https://github.com/mqhe2007/a-at-ui/blob/main/packages/a-at-ui/README.zh-CN.md)

Frontend runtime and protocol assets for agent-driven UI streams.

## Install

```bash
npm install a-at-ui
```

## Exports

- `a-at-ui`: package entry for protocol types and shared utilities
- `a-at-ui/runtime/vue`: Vue 3 frontend runtime adapter

## Usage

Use the official frontend runtime adapter for your target frontend stack. See the full documentation at https://a-at-ui.mengqinghe.com.
