# a-at-ui

[English](https://github.com/mqhe2007/a-at-ui/blob/main/packages/a-at-ui/README.md)

面向 Agent 驱动 UI 命令流的前端运行时与协议资源。

## 安装

```bash
npm install a-at-ui
```

## 导出内容

- `a-at-ui`：协议类型与共享工具的包入口
- `a-at-ui/runtime/vue`：Vue 3 前端运行时适配器

## 使用

请根据目标前端栈使用官方前端运行时适配入口。完整文档见 https://a-at-ui.mengqinghe.com。
